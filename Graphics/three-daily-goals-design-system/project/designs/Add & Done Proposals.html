Add & Done — placement proposals

Two small changes that make the most common action — creating a task — obvious, and let you finish one without hunting for the back button. Shown before → after for iOS and macOS.

1

Surface the add button next to Compass Check

Today the + sits as one of five equal-weight glyphs in the top toolbar pill — visually it reads as a utility, not the primary thing you came to do. We promote it to a labelled New Task button stacked directly below Start Compass Check, so the two daily actions live together. The toolbar keeps share / import / stats only.

2

A clear “Done” on the new-task screen · iOS

When you create a task, the editor pushes onto the navigation stack. Right now the only way out is the ‹ back chevron — so finishing feels like abandoning. We add a bold Done at the top-right: it commits the task and pops the screen in one tap, the standard iOS pattern. The back chevron stays for anyone who reaches for it.
