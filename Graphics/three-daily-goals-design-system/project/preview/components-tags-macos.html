macOS — Tags in context
The shipping macOS app draws tags as OS-default grey chips, which disappear against grey panels. This is the same canonical tag (radius 4, soft-orange tint default, solid-orange selected) shown in the two places tags appear on Mac: the label picker and the filter bar.
Label picker
Solid = applied to this task, tint = available. Color now carries meaning — you can see which labels are already on the task at a glance, instead of every chip looking identical.

Implementation (SwiftUI)
Drop-in TagChip. isApplied drives both filter “active” and label “on this task”.
extension Color {
    // brand orange — #EA580C
    static let tdgBrand   = Color(red: 234/255, green: 88/255, blue: 12/255)
    // tint-on-light text — #B4500F
    static let tdgTagText = Color(red: 180/255, green: 80/255, blue: 15/255)
}

struct TagChip: View {
    let label: String
    var isApplied: Bool = false   // applied / active filter

    var body: some View {
        Text(label)
            .font(.system(size: 12, weight: isApplied ? .semibold : .medium))
            .foregroundStyle(isApplied ? .white : Color.tdgTagText)
            .padding(.horizontal, 11)
            .padding(.vertical, 4)
            .background(
                RoundedRectangle(cornerRadius: 4)
                    .fill(isApplied ? Color.tdgBrand : Color.tdgBrand.opacity(0.09))
            )
            .overlay(
                RoundedRectangle(cornerRadius: 4)
                    .stroke(isApplied ? Color.tdgBrand
                                      : Color.tdgBrand.opacity(0.28), lineWidth: 1)
            )
    }
}
